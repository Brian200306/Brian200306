# Visual resources and references

## Original artwork

The header and the two-area overview SVGs were made for Brian Victor. His name remains static while blue, cyan and teal background layers move, with amber accents. A complete static version is selected when reduced motion is requested. The cards use typography without pictograms. They summarize ERP, API and automation work alongside game-related hobbies. Desktop shows both areas side by side; mobile presents games first. Both have Portuguese and English versions and light and dark themes.

The presentation does not use another developer's avatar, biography, project descriptions or statistics. No private project code, client data or operational screenshots are included.
